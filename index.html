Monitor de Reactor Térmico

El operador de turno ingresa lecturas de temperatura una por una. El sistema las clasifica en tiempo real y genera un informe al cerrar el turno.

while True + break listas dinámicas append() len() if anidado for de análisis 30 minutos
// La historia

Situación

Un reactor térmico industrial debe mantenerse dentro de un rango seguro de temperatura. Durante el turno, el operador mide la temperatura manualmente y la ingresa al sistema.

El sistema clasifica cada lectura al instante. Cuando el operador termina el turno, ingresa -1 y el sistema genera el informe completo.

No hay un número fijo de lecturas: el turno puede durar 3 o 20 mediciones.

💡 Las lecturas se guardan en listas a medida que llegan. Al final, el programa las recorre con for para calcular el informe. Dos momentos distintos: cargar con while, analizar con for.
// Por qué este ejercicio es distinto

La diferencia con el cajero

🔄 Cajero vs Reactor

Cajero
Loop for i in range(5) — siempre exactamente 5 veces, sin excepción.
Reactor
Loop while True con break cuando el usuario ingresa -1 — puede ser 1 lectura o 50.
Cajero
Dos posibles acciones (Déposito / Retiro) — dos listas.
Reactor
Tres posibles estados (Normal / Alarma / Crítico) — tres listas.
Cajero
El if anidado verifica un límite (saldo disponible).
Reactor
El if anidado clasifica por severidad: si ya sabés que supera 60°C, ¿también supera 80°C?

// Las tres categorías

Clasificación de temperaturas

RangoEstadoMensaje
menor a 60°C 🟢 NORMAL dentro del rango seguro.
60°C a 79.9°C 🟡 ALARMA temperatura elevada. Monitorear.
80°C o más 🔴 CRITICO DETENER EL PROCESO.
💡 El if anidado: primero preguntás si la temperatura supera 60. Si la respuesta es sí, adentro de ese bloque preguntás si también supera 80. Así se determina si es ALARMA o CRÍTICO. 
if temp >= 60:          # supera el umbral?
    if temp >= 80:      # if anidado: es critico?
        criticos.append(temp)
        print("CRITICO")
    else:
        alarmas.append(temp)
        print("ALARMA")
else:
    normales.append(temp)
    print("NORMAL")
// La estructura del programa

Cómo organizarlo

Fase 1 — Cargar lecturas con while

Declará estas variables antes del while:

normales = [] # lecturas < 60 alarmas = [] # lecturas entre 60 y 79.9 criticos = [] # lecturas >= 80 contador = 0 # cantidad total de lecturas validas

El while corre hasta que el usuario ingresa -1:

while True: contador += 1 print(f"Lectura #{contador} | ", end="") temp = float(input("Temperatura (C): ")) if temp == -1: contador -= 1 # el -1 no cuenta como lectura print("Turno cerrado.") break # clasificar y guardar... if temp >= 60: if temp >= 80: # if ANIDADO criticos.append(temp) print("CRITICO") else: alarmas.append(temp) print("ALARMA") else: normales.append(temp) print("NORMAL")

Fase 2 — Analizar con for

Después del while, reconé las tres listas para calcular el informe. Armá primero una sola lista con todas las lecturas:

# Juntar todas las lecturas en una sola lista todas = normales + alarmas + criticos # Calcular maximo, minimo y promedio SIN usar max(), min() ni sum() if len(todas) > 0: maximo = todas[0] minimo = todas[0] total = 0 for t in todas: total += t if t > maximo: maximo = t if t < minimo: minimo = t promedio = total / len(todas)
💡 La concatenación de listas:
todas = normales + alarmas + criticos crea una nueva lista con todos los elementos de las tres. Es la forma más limpia de calcular máximo, mínimo y promedio sobre todo el turno de una vez.

Siempre verificá con if len(todas) > 0: antes de operar sobre la lista, por si el operador cerró el turno sin ingresar ninguna lectura.

Nivel de dificultad

✅ Mínimo

El sistema recibe lecturas con el while, clasifica cada una en tiempo real (NORMAL / ALARMA / CRÍTICO) y al cerrar muestra cuántas hay de cada tipo.

⭐ Completo

Además del mínimo, muestra el informe completo: temperatura máxima, mínima y promedio del turno. Sin max(), min() ni sum().
